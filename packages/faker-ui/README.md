# @baicie/faker-ui

Browser UI used to configure and inspect mocks created by the Baicie Faker
plugins.

This package is normally installed transitively by `@baicie/vite-plugin-faker`
or `@baicie/webpack-plugin-faker`. Public API documentation and usage examples
are available in the [repository README](https://github.com/baicie/vite-plugin-faker#readme).
